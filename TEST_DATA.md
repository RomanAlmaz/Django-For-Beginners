# Test data (тестовые данные)

`loaddata` и **fixtures** - **не обязательная** часть Django. Это способ быстро загрузить готовые данные из JSON-файла.

## Основной путь в курсе

```
Models → migrate → Django Admin → создаём данные вручную
```

Так новичок понимает, откуда берутся записи в базе.

## Когда использовать fixtures

Fixtures полезны, если вы:

- хотите быстро проверить урок без ручного ввода в админке;
- изучаете уже готовый урок и не хотите создавать 5 товаров вручную;
- сравниваете два урока с одинаковым набором данных.

**Fixtures не заменяют** понимание моделей, миграций и админки.

## Как загрузить тестовые данные

В уроках с 05 по 10 (и далее) может быть файл:

```
shop/fixtures/initial_data.json
```

Команда:

```bash
python manage.py migrate
python manage.py loaddata initial_data
```

Выполняйте `loaddata` **после** `migrate`, в той папке урока, где вы работаете.

## Что внутри fixture

Обычно:

- категории и товары (с Lesson 05);
- отзывы (с Lesson 08, если есть в JSON);
- в Lesson 10 отзывы в fixture **не включены** - создайте их после регистрации на сайте.

## Если loaddata выдает ошибку

1. Убедитесь, что выполнили `migrate`.
2. Удалите `db.sqlite3` и снова `migrate` + `loaddata` (чистая база).
3. Или создайте данные через `/admin/` - это всегда работает.

## Итог

| | Обязательно? |
|---|--------------|
| `migrate` | Да |
| `createsuperuser` + Admin | Да, для наполнения базы (основной путь) |
| `loaddata` | Нет, опционально для ускорения |
