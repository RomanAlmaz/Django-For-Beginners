Django уже содержит готовую **админ-панель**. Мы зарегистрируем модели и настроим удобный интерфейс для добавления, изменения и удаления категорий и товаров.

## Что такое Django Admin

Django Admin - встроенная панель управления данными. Она автоматически создает формы на основе моделей. Администратор сайта может работать с базой через браузер, без правки кода.

Админка доступна по адресу `/admin/`. Для входа нужен **суперпользователь** (superuser).

## Шаг 1. Создайте суперпользователя

Сначала подготовьте базу:

```bash
python manage.py migrate
```

💡 Если хотите быстро заполнить базу готовыми категориями и товарами, см. [Test data](../../TEST_DATA.md) (`loaddata` - опционально).

Создайте суперпользователя:

```bash
python manage.py createsuperuser
```

Django попросит:

- username (например, `admin`);
- email (можно оставить пустым);
- password (два раза, символы не отображаются при вводе).

Суперпользователь имеет полный доступ к админке и ко всем моделям.

## Шаг 2. Регистрация моделей в admin.py

Откройте `shop/admin.py`:

```python
from django.contrib import admin

from shop.models import Category, Product


@admin.register(Category)
class CategoryAdmin(admin.ModelAdmin):
    list_display = ['name', 'description']
    search_fields = ['name', 'description']


@admin.register(Product)
class ProductAdmin(admin.ModelAdmin):
    list_display = ['name', 'price', 'is_featured', 'created_at']
    list_filter = ['is_featured', 'created_at']
    search_fields = ['name', 'description']
```

### Что здесь происходит

| Настройка | Назначение |
|-----------|------------|
| `@admin.register(Category)` | Подключает модель к админке |
| `CategoryAdmin` | Класс с настройками отображения |
| `list_display` | Колонки в списке записей |
| `search_fields` | Поля для поиска вверху списка |
| `list_filter` | Фильтры справа (для Product) |

Без регистрации модели в `admin.py` они не появятся в админке (кроме встроенных User и Group).

## Шаг 4. Работа в админке

Попробуйте:

1. Открыть список **Products** - колонки name, price, is_featured, created_at из `list_display`.
2. Использовать **поиск** по названию товара (`search_fields`).
3. Отфильтровать товары по **is featured** (`list_filter`).
4. Добавить новый товар через кнопку **Добавить товар**.
5. Изменить существующую категорию.
6. Удалить тестовый товар (Django попросит подтверждение).

Изменения в админке сохраняются в `db.sqlite3` и сразу видны на сайте (на `/` и `/products/`), потому что views читают данные из той же базы.

## Шаг 5. Проверка связи с сайтом

1. В админке отметьте товар как **Is featured**.
2. Откройте [http://127.0.0.1:8000/](http://127.0.0.1:8000/) - товар должен появиться в разделе «Избранные товары».
3. Снимите галочку - товар пропадет с главной.

Так вы видите, что админка и публичный сайт работают с одной базой данных.
