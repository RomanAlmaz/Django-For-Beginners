# Contributing

Спасибо, что интересуетесь развитием **Django for Beginners**. Проект открыт для исправлений, предложений и новых уроков.

## Как внести изменение

```
fork репозитория на GitHub
        ↓
clone вашего fork локально
        ↓
откройте нужный lesson (например lessons/07-crud/)
        ↓
внесите изменения
        ↓
commit с понятным сообщением
        ↓
push в ваш fork
        ↓
pull request в основной репозиторий
```

### Пошагово

1. **Fork** - на GitHub нажмите Fork, чтобы создать копию репозитория в вашем аккаунте.
2. **Clone** - склонируйте fork на свой компьютер:

   ```bash
   git clone https://github.com/RomanAlmaz/Django-For-Beginners.git
   cd Django-For-Beginners
   ```

3. **Lesson** - каждый урок в `lessons/` - отдельный Django-проект. Работайте в папке конкретного урока.
4. **Изменения** - правьте код, README или документацию. Следуйте стилю существующих уроков.
5. **Commit** - одно логичное изменение - один commit (или несколько связанных):

   ```bash
   git add .
   git commit -m "Fix typo in lesson 08 README"
   ```

6. **Pull Request** - отправьте branch в основной репозиторий и опишите, что изменили и зачем.

## Что можно улучшить

- опечатки и неточности в README;
- улучшение объяснений для новичков;
- исправления в коде уроков;
- новые уроки (13 Orders, 14 Pagination и далее);
- переводы и локализация.

## Правила для pull request

- **Один урок - одна папка.** Не смешивайте изменения из разных lessons без необходимости.
- **Не коммитьте** `db.sqlite3`, `__pycache__/`, `*.pyc`, `venv/`.
- README уроков - на русском, без длинного тире (используйте обычный `-`).
- Новый концепт - один урок, одна главная тема (см. `CURSOR_INSTRUCTIONS.txt`).
- Если меняете код урока N, проверьте, что проект запускается: `migrate` + `runserver`.

## Новый урок

Если добавляете урок (например Lesson 13 - Orders):

1. Скопируйте проект из предыдущего урока как базу.
2. Добавьте только одну новую тему.
3. Создайте README с секциями: что изучается, запуск, шаги, проверка, домашнее задание, **После этого урока**.
4. Обновите roadmap в корневом `README.md`.

## Вопросы

Если не уверены, нужен ли PR - откройте Issue с описанием идеи. Обсудим до начала работы.
